# Camello 開発ロードマップ

## プロジェクト概要

CamelloはRust製のPerlコードフォーマッタです。Rowanライブラリを利用してCST（具象構文木）ベースの実装を行い、コメントや空白を保持しながら一貫したコーディングスタイルを適用します。

## 開発フェーズ

### Phase 1: 基盤構築 🏗️

**目標**: プロジェクトの基本構造と依存関係の整備

#### 1.1 依存関係のセットアップ
- **Cargo.toml更新**
  - `rowan` - CST操作のコア
  - `logos` - 高性能な字句解析
  - `clap` - CLI構築
  - `smol_str` - 効率的な文字列処理
  - `insta` (dev-dependency) - スナップショットテスト

#### 1.2 基本モジュール構造
```
src/
├── main.rs          # エントリーポイント
├── lib.rs           # ライブラリ公開インターフェース
├── syntax_kind.rs   # SyntaxKind enum定義
├── lexer.rs         # Logosベーストークナイザー
├── parser.rs        # Rowanベースパーサー
├── formatter.rs     # CSTフォーマッタ
└── cli.rs           # Clapベース CLI
```

**対象構文**:
- 変数: `$var`, `@array`, `%hash`

#### 2.3 最小パーサー
**対象構造**:
```perl

# サブルーチン定義

}
```

### Phase 3: フォーマット機能 ✨

**目標**: 基本的なフォーマットルールの実装

#### 3.1 基本フォーマッタ
- CSTの深さ優先走査
- インデント管理（4スペース）
- トークン間のスペース調整

#### 3.2 フォーマットルール
1. **インデント**
   - ブロック開始で +4スペース
   - ブロック終了で -4スペース

2. **スペース**
   - 演算子前後: `$a = $b + $c`
   - カンマ後: `func($a, $b, $c)`
   - キーワード後: `my $var`, `sub name`

3. **改行**
   - 文終了（`;`）で改行
   - ブロック開始（`{`）は同一行（K&Rスタイル）

#### 3.3 テスト基盤
- Instaを使ったスナップショットテスト
- 入力Perlコード → 期待出力の完全一致検証
